# AI智能运营助手三语国际化设计说明

## 背景与目标

项目定位面向国际商家和跨境电商运营场景，需要支持中文、英文、葡语三种语言，提升对 Olist 葡语数据集和海外商家演示场景的适配度。

一期目标是实现应用级语言切换：

- 支持 `zh-CN`、`en-US`、`pt-BR` 三种语言。
- 切换语言后，前端菜单、按钮、表格列名、表单标签、提示信息、空状态、页面标题等界面文字即时切换。
- Element Plus 内置组件文字跟随当前语言切换。
- AI 文案、运营报告、商品对比报告、差评回复请求使用当前语言作为输出语言。
- 原始评论内容保持原文展示，不在一期自动翻译。

## 不做范围

- 不做用户级语言偏好入库。
- 不做原始评论全文批量翻译。
- 不修改数据库表结构。
- 不改 JWT 鉴权方案。
- 不改后端接口路径。

## 语言代码

| 语言 | 代码 | 展示名称 |
| --- | --- | --- |
| 中文 | `zh-CN` | 简体中文 |
| 英文 | `en-US` | English |
| 葡语 | `pt-BR` | Português |

默认语言为 `zh-CN`。前端将当前语言保存到 `localStorage`，刷新页面后保持用户上次选择。

## 前端架构

前端引入 `vue-i18n` 管理界面文案。

新增模块：

- `src/i18n/index.ts`：创建 i18n 实例、维护语言列表、读取和保存当前语言。
- `src/i18n/locales/zh-CN.ts`：中文文案字典。
- `src/i18n/locales/en-US.ts`：英文文案字典。
- `src/i18n/locales/pt-BR.ts`：葡语文案字典。
- `src/stores/locale.ts`：Pinia 语言状态，提供切换语言方法。

改造点：

- `main.ts` 接入 `vue-i18n`，并让 Element Plus locale 从当前语言派生。
- `MainLayout.vue` 增加语言切换控件，放在顶部工具区。
- 各页面将硬编码中文替换为 `$t()` 或 `t()`。
- 前端固定枚举展示，如 `positive / neutral / negative`、`quality / logistics / price / service / size / other`，通过本地字典映射显示。

## Element Plus 语言切换

Element Plus 通过 `ElConfigProvider` 接收 locale。应用根组件根据当前语言映射到：

- `zh-CN` -> `zh-cn`
- `en-US` -> `en`
- `pt-BR` -> `pt`

这样分页、日期、选择器等组件内置文字会随语言切换。

## AI 输出语言

后端 DTO 和 Python 服务已经支持 `language` 字段，一期只需要前端统一传当前语言。

涉及请求：

- AI 文案生成。
- 商品运营报告。
- 商家运营报告。
- 差评回复生成。
- 商品 A/B 对比报告。

前端不再写死 `language: 'zh-CN'`，而是从语言 store 获取当前语言。

## 原始评论展示策略

原始评论内容保持数据集原文，例如 Olist 的葡语评论继续显示葡语。

原因：

- 原始评论属于用户原始数据，保留原文更可信。
- 全量自动翻译会增加 AI 成本和响应时间。
- 翻译结果需要额外缓存和来源标记，适合二期扩展。

二期可以追加单条评论“翻译”按钮，按需翻译并缓存结果。

## 后端与 Python 服务

后端暂不新增接口。

需要确认：

- 默认语言仍为 `zh-CN`。
- AI 相关缓存 key 已包含 language，避免中文报告和英文报告互相覆盖。
- Python prompt 中明确要求按传入语言输出。

如果后端返回固定中文错误信息，前端一期以接口错误原文展示；后续可用错误码映射为前端多语言文案。

## 错误处理与回退

- 如果 `localStorage` 中保存了未知语言，回退到 `zh-CN`。
- 如果某个翻译 key 缺失，回退到中文或 key 本身，避免页面崩溃。
- AI 服务失败时仍展示当前语言下的前端错误提示。

## 测试策略

前端：

- 新增语言工具单元测试，验证默认语言、语言切换、未知语言回退。
- 更新现有导航测试，验证三种语言下菜单数量和路由稳定。
- 运行 `npm run typecheck` 和 `npm run build`。

后端/Python：

- 不改接口结构时不新增后端测试。
- 保留已有 AI language 相关测试。

## 验收标准

- 页面顶部可以切换中文、英文、葡语。
- 切换后无需刷新，菜单、标题、按钮、表格、提示文案立即变化。
- 刷新页面后保持上次语言。
- 生成 AI 文案、运营报告、差评回复、商品对比报告时，输出语言与当前界面语言一致。
- 原始评论内容保持原文。
- 前端构建通过，现有核心页面可正常访问。
