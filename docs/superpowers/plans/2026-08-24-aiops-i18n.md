# AIops Trilingual i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Chinese, English, and Brazilian Portuguese language switching for the AI operations assistant UI and AI-generated outputs.

**Architecture:** Use `vue-i18n` for app text, a Pinia locale store for current language state, and Element Plus locale mapping through `ElConfigProvider`. Existing backend/Python `language` fields stay unchanged; the frontend passes the selected language instead of hard-coded `zh-CN`.

**Tech Stack:** Vue 3, Pinia, Vue Router, Element Plus, `vue-i18n`, Node test runner, Vite.

**Spec:** `docs/superpowers/specs/2026-08-24-aiops-i18n-design.md`

## Global Constraints

- Support exactly `zh-CN`, `en-US`, and `pt-BR` in phase one.
- Default language is `zh-CN`.
- Persist selected language in `localStorage`.
- Do not translate original raw comment content in phase one.
- Do not change database schema.
- Do not change backend API paths.
- Do not replace JWT authentication.
- AI content, reports, negative replies, and product comparison requests must use the selected language.
- Keep current frontend layout style; add a compact language selector to the top toolbar.

- [ ] **Step 5: Create i18n index**

Create `aiops-frontend/src/i18n/index.ts`:

```ts
import zhCnElement from 'element-plus/es/locale/lang/zh-cn'
import enElement from 'element-plus/es/locale/lang/en'
import ptElement from 'element-plus/es/locale/lang/pt'
import type { Language } from 'element-plus/es/locale'
import { createI18n } from 'vue-i18n'

import enUS from './locales/en-US'
import ptBR from './locales/pt-BR'
import zhCN from './locales/zh-CN'

export type AppLocale = 'zh-CN' | 'en-US' | 'pt-BR'

export const localeStorageKey = 'aiops_locale'
export const defaultLocale: AppLocale = 'zh-CN'

export const supportedLocales: Array<{ code: AppLocale; label: string; shortLabel: string }> = [
  { code: 'zh-CN', label: '简体中文', shortLabel: '中' },
  { code: 'en-US', label: 'English', shortLabel: 'EN' },
  { code: 'pt-BR', label: 'Português', shortLabel: 'PT' }
]

export const elementPlusLocales: Record<AppLocale, Language> = {
  'zh-CN': zhCnElement,
  'en-US': enElement,
  'pt-BR': ptElement
}

export const normalizeLocale = (value: unknown): AppLocale => {
  return supportedLocales.some((item) => item.code === value) ? (value as AppLocale) : defaultLocale
}

export const i18n = createI18n({
  legacy: false,
  locale: normalizeLocale(localStorage.getItem(localeStorageKey)),
  fallbackLocale: defaultLocale,
  messages: {
    'zh-CN': zhCN,
    'en-US': enUS,
    'pt-BR': ptBR
  }
})
```

- [ ] **Step 6: Create locale store**

Create `aiops-frontend/src/stores/locale.ts`:

```ts
import { defineStore } from 'pinia'
import { computed, ref } from 'vue'

import { defaultLocale, elementPlusLocales, i18n, localeStorageKey, normalizeLocale, supportedLocales } from '@/i18n'
import type { AppLocale } from '@/i18n'

export const useLocaleStore = defineStore('locale', () => {
  const locale = ref<AppLocale>(normalizeLocale(localStorage.getItem(localeStorageKey) || defaultLocale))

  const setLocale = (nextLocale: AppLocale) => {
    locale.value = normalizeLocale(nextLocale)
    i18n.global.locale.value = locale.value
    localStorage.setItem(localeStorageKey, locale.value)
    document.documentElement.lang = locale.value
  }

  setLocale(locale.value)

  return {
    locale,
    languages: supportedLocales,
    elementLocale: computed(() => elementPlusLocales[locale.value]),
    setLocale
  }
})
```
